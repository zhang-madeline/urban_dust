# urban_dust
Scripts for testing urban dust 

### Folder Directory

- **adnet-analysis**
    - scripts for AD-NET analysis
- **rain-analysis**
    - scripts for JMA radar data for rain
- **wrf-namelist-archive**
    - namelist.input and namelist.wps for all test runs
- **wrf-output-analysis**
    - scripts and pngs for wrfout files from WRF simulations
